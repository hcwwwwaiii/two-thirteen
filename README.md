# 02:13 — The person outside

[Play the game](https://hcwwwwaiii.github.io/two-thirteen/)

An English, typed-command horror story. Chapter one is a playable draft.

Read the room, infer what to do, and type your action. There are no action menus. You can type `help` for input guidance or `hint` when stuck.

Progress is saved in this browser on this device. Sound starts off and can be enabled in the game.

Content note: psychological horror and the death of a family member.

Built with HTML, CSS and JavaScript. No AI service, account or server is required to play. Download the files and open `index.html` for an offline copy.

Published from the tested playtest-6 build.
